# Welcome to the PyADQL Documentation!

**PyADQL** parses [ADQL](https://www.ivoa.net/documents/ADQL/) queries --
the IVOA-standardized query language used by astronomical TAP services
(Gaia, SIMBAD, VizieR, ...) -- into a typed Python abstract syntax tree.

This document contains all the information you need to understand and use
PyADQL: start with [Introduction](introduction.md) for the big picture,
[Tutorial](tutorial.md) for a hands-on walkthrough, and
[Operation Manual](operation_manual.md) / [Reference Manual](reference_manual.md)
for day-to-day usage. For a deep dive into the AST returned by
`parse_adql()`, see the [AST guided tour](AST.md).
